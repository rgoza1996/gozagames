# GozaGames

Public website and privacy policy for Sudoku by Rogie.

## Publishing

GitHub Pages serves the `main` branch from the repository root. Static HTML and CSS only; no build step, external fonts, or client-side analytics.

- Homepage: `index.html`
- App privacy policy: `sudoku/privacy/index.html`
- Shared Parchment theme: `style.css`

The Android application source is maintained separately.
